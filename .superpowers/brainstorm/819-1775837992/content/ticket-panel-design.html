A — Conversation + Properties Sidebar

Conversation thread takes up most of the panel. Ticket properties (status, priority, assignee, queue, category) live in a narrow sidebar on the right. Closest to Zendesk.

B — Properties on Top, Thread Below

Ticket metadata shown as pills at the top. Full width for the conversation thread below. More vertical space for the thread, but properties are less editable at a glance.

Both have the reply/internal note toggle. A gives more room to edit properties inline. Which feels better?
